## 1. Область применения

Регламент определяет порядок создания задач на доработку CRM-системы. Обязателен для всех сотрудников, инициирующих задачи на улучшение продукта.

## 2. Ответственные и участники

| Роль | Участник | Функции |
|------|----------|---------|
| Ответственный | КАМ клиента | Создание задачи, заполнение атрибутов, передача на валидацию |
| Участник | Клиент / внутренний заказчик | Формулировка бизнес-потребности |
| Получатель | Product Owner | Приём задачи на валидацию |

## 3. Общие положения

Этап является стартовой точкой жизненного цикла задачи. На этом этапе фиксируется бизнес-потребность без детализации технической реализации.

## 4. Порядок выполнения

### 4.1. Когда создаётся задача

- Клиент обращается к КАМу с запросом на доработку (через внешнюю систему, почту или напрямую).
- Внутренний сотрудник инициирует задачу по собственной инициативе.

### 4.2. Создание задачи в Трекере

1. Создать задачу в очереди CRM с типом **«Улучшение»**.
2. Заполнить обязательные атрибуты (см. таблицу ниже).
3. Назначить исполнителем **Product Owner**.
4. Оставить статус **«Открыта»**.

### 4.3. Обязательные атрибуты

| Атрибут | Требование | Пример |
|---------|-----------|--------|
| Название | Начинается с мнемоники клиента | `SRV. Добавить экспорт отчёта в Excel` |
| Тип | Улучшение | — |
| Тег | Мнемоника клиента | `SRV` |
| Блок «Цель / Проблема» | Описывает **что** и **зачем**, не **как** | «При просмотре таблицы пользователь тратит избыточное время на...» |
| Приоритет | ?? | ?? |

### 4.4. Рекомендуемые атрибуты

| Атрибут | Описание |
|---------|---------|
| Юзкейс | Сценарий использования от лица пользователя |
| Пример реализации | Предложение клиента (носит рекомендательный характер; команда вправе предложить альтернативу) |

### 4.5. Завершение этапа

Задача готова к передаче, когда:
- заполнены все обязательные атрибуты,
- исполнителем назначен Product Owner,
- статус — «Открыта».

## 5. Критерии завершения

- [ ] Тип задачи — «Улучшение»
- [ ] В названии и теге присутствует мнемоника клиента
- [ ] Заполнен блок «Цель / Проблема» с описанием бизнес-потребности
- [ ] Исполнитель — Product Owner
- [ ] Статус — «Открыта»

## 6. Учёт трудозатрат

По усмотрению автора задачи. При необходимости — в основную задачу.
