## 1. Область применения

Регламент определяет порядок согласования результатов бизнес-анализа с клиентом. Обязателен для сотрудников, ответственных за коммуникацию с заказчиком.

## 2. Ответственные и участники

| Роль | Участник | Функции |
|------|----------|---------|
| Ответственный | КАМ / автор задачи | Согласование постановки с клиентом, управление статусами |
| Участник | Клиент | Рассмотрение и утверждение бизнес-постановки |
| Исполнитель | Команда БА | Внесение правок при возврате на доработку |

## 3. Общие положения

Этап является контрольной точкой: клиент подтверждает, что предложенное решение корректно отражает его потребность, и задача готова к оценке трудозатрат.

## 4. Порядок выполнения

### 4.1. Когда задача попадает на этап

- Подзадача «Бизнес Анализ» в статусе «Согласование КАМ»
- Исполнитель подзадачи — КАМ / автор задачи
- Созданы подзадачи «Разработка» (и «Дизайн» при необходимости) в статусе «Открыта»

### 4.2. Процедура согласования

1. КАМ передаёт клиенту бизнес-постановку для рассмотрения.
2. Переводит подзадачу «Бизнес Анализ» в статус **«Согласование Клиентом»** — фиксирует момент передачи.
3. Клиент рассматривает: бизнес-постановку, юзкейсы, визуальные материалы (при наличии).

### 4.3. Варианты решения

**Вариант А — Постановка согласована**

1. Перевести подзадачу «Бизнес Анализ» в статус **«Закрыта»**.
2. Перевести подзадачи «Разработка» (и «Дизайн») в статус **«Оценка задачи»**.
3. Назначить исполнителями подзадач соответствующих руководителей направлений (тимлиды, лид дизайна).
4. Задача переходит на этап «Оценка задачи».

**Вариант Б — Постановка требует доработки**

1. Перевести подзадачу «Бизнес Анализ» в статус **«На доработку»**.
2. Назначить исполнителем подзадачи ответственного бизнес-аналитика.
3. Зафиксировать в комментарии перечень замечаний клиента.
4. Задача возвращается команде БА.

> При существенных изменениях, влияющих на объём работ, КАМу рекомендуется инициировать повторную консультацию с БА до фиксации итоговых изменений.

### 4.4. Завершение этапа

Этап завершён после выполнения одного из двух сценариев.

## 5. Критерии завершения

**Постановка согласована:**
- [ ] Подзадача «Бизнес Анализ» закрыта
- [ ] Подзадачи «Разработка» / «Дизайн» в статусе «Оценка задачи»
- [ ] Исполнители назначены (тимлиды, лид дизайна)

**Возврат на доработку:**
- [ ] Замечания зафиксированы в комментарии
- [ ] Подзадача «Бизнес Анализ» в статусе «На доработку»
- [ ] Исполнитель — бизнес-аналитик

## 6. Учёт трудозатрат

По усмотрению КАМа. При необходимости — в основную задачу.
