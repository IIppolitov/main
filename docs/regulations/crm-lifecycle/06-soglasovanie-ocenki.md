# Этап 6 — Согласование оценки

## 1. Область применения

Регламент определяет порядок согласования оценки трудозатрат с клиентом. Обязателен для сотрудников, ответственных за коммуникацию с заказчиком и подготовку задач к разработке.

## 2. Ответственные и участники

| Роль | Участник | Функции |
|------|----------|---------|
| Ответственный | КАМ / автор задачи | Формирование сводной оценки, согласование с клиентом |
| Участник | Клиент | Утверждение оценки |
| Консультант | Тимлиды, Релиз-менеджер | Разъяснения по оценке при необходимости |

## 3. Общие положения

На этом этапе клиент получает полную картину трудозатрат и подтверждает готовность реализовать задачу в согласованном объёме. Только после этого задача может быть включена в спринт.

## 4. Порядок выполнения

### 4.1. Когда задача попадает на этап

- Все подзадачи «Разработка» / «Дизайн» в статусе «Согласование КАМ»
- У всех подзадач заполнено поле «Оценка»
- В основной задаче заполнены поля «Оценка» и «Оценка разработки»

### 4.2. Формирование сводной оценки для клиента

КАМ собирает итоговую цифру из поля **«Оценка»** основной задачи (таблица оценки, включая ревью, риски, деплой) и прибавляет **фактически затраченное время** на БА (из поля «Оценка БА» подзадачи «Бизнес Анализ»).

> Итоговая цифра для клиента = «Оценка» (план) + «Оценка БА» (факт, уже потраченный).

### 4.3. Варианты решения

**Вариант А — Оценка согласована**

1. Перевести все подзадачи «Разработка» / «Дизайн» в статус **«Готово к разработке»**.
2. Задача готова к набору в спринт.

**Вариант Б — Оценка требует корректировки**

1. Вернуть несогласованные подзадачи на этап «Оценка задачи» или «Бизнес-анализ» в зависимости от причины.
2. Зафиксировать замечания в комментарии.

**Вариант В — Задача отменена**

1. Закрыть основную задачу и все дочерние подзадачи.
2. Зафиксировать причину отмены в комментарии.

### 4.4. Особый случай: наличие подзадачи «Дизайн»

Задача может быть взята в разработку только после утверждения визуальных материалов. Разработка до закрытия подзадачи «Дизайн» не начинается.

## 5. Критерии завершения

**Оценка согласована:**
- [ ] Все подзадачи в статусе «Готово к разработке»
- [ ] Поле «Оценка» в подзадачах «Разработка» содержит часы разработки (без буфера)

**Возврат на доработку:**
- [ ] Замечания зафиксированы в комментарии
- [ ] Подзадачи возвращены на соответствующий этап

**Отмена:**
- [ ] Все задачи закрыты с комментарием о причине

## 6. Учёт трудозатрат

По усмотрению КАМа. При необходимости — в основную задачу.
