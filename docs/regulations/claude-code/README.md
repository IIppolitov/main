# Claude Code в командах разработки

Три документа: общая база и по одному на команду. Читать в таком порядке —
основы обязательны всем, документ команды дополняет их спецификой проекта.

| Документ | Кому | О чём |
|---|---|---|
| [osnovy.md](osnovy.md) | всем разработчикам ИТ | доступ, VPN, установка, обвязка, ядро правил, работа с данными, приёмы и анти-паттерны |
| [pbeadmin.md](pbeadmin.md) | команде админки | агенты и команды `pbeadmin`, гейты приёмки, технические запреты |
| [pbeapp.md](pbeapp.md) | команде приложения | агенты и конвейер `pbeapp`, артефакты задачи, мультибренд и сборка |

Порядок настройки VPN вынесен в [../vpn/](../vpn/) — он публикуется в раздел Вики про ВПН,
а не сюда. Основы на него ссылаются.

**Статус смешанный.** Раздел «Ядро» в основах и правила по работе с данными
обязательны. Остальное — приёмы и рекомендации: спорить с ними можно и нужно
предметно.

**Источник истины по коду и внутреннему процессу проекта — `CLAUDE.md` в корне
его репозитория.** Документы команд на него ссылаются, а не пересказывают:
разошлись — прав `CLAUDE.md`.

Все три — черновики, ответственный Ипполитов Иван. Правим здесь, потом
переносим в Вики. Открытые вопросы по выдаче инструмента — в
[../../backlog.md](../../backlog.md), раздел «Claude Code в командах разработки».
