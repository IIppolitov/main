## 1. Зачем это нужно

Claude Code работает через сервисы Anthropic, и из российской сети они недоступны.
Поэтому доступ к инструменту выдаётся комплектом: подписка плюс персональная
конфигурация VPN. Без включённого VPN Claude Code не запустится — ни в терминале,
ни в расширении IDE.

Подключение под Claude Code **отдельное**: свой профиль в Happ со своими правилами
роутинга. Всё остальное — Трекер, Вики, боевые стенды, почта — ходит как ходило,
напрямую. Это не косметика: если завернуть в туннель весь трафик, рабочие ресурсы
компании начнут ходить в них через зарубежный узел, а часть просто перестанет
открываться.

**Happ — клиент, а не VPN-сервис.** Своих серверов у него нет, и «официальных
VPN от Happ» не существует — предложения с таким названием к разработчику
отношения не имеют. Конфигурацию выдаём мы — вместе с доступом к Claude Code, см. п. 2.

## 2. Что нужно получить

| Что | Откуда |
|---|---|
| Приложение Happ | сайт разработчика [happ.su](https://www.happ.su/main), App Store, Google Play |
| Персональная VLESS-строка (`vless://…`) | у CTO — конфигурации выпускает он |

Подписку на Claude Code выдаёт директор департамента ИТ, конфигурацию VPN — CTO
(инфраструктура его зона). Это два разных обращения; кто сейчас в этих ролях —
[оргструктура](../../company/org-structure.md).

**VLESS-строка — это пароль.** В ней ключ подключения. Хранится в парольном
менеджере, не пересылается коллегам, не вставляется в задачу Трекера, в чат
и в репозиторий. Строка персональная: по ней видно, кто именно ходил.
Не работает или скомпрометирована — запрашиваем у CTO новую, а не берём чужую.

## 3. Порядок настройки

### 3.1. Установить Happ

Приложение есть под Windows, macOS, Linux, iOS, Android и телевизионные платформы —
ставим на ту машину, где будет работать Claude Code. Для iOS и macOS ставится
из App Store, для остальных — с сайта разработчика.

### 3.2. Добавить конфигурацию

1. Скопировать присланную строку `vless://…` целиком, вместе с текстом после `#` —
   это имя профиля, по нему подключение будет видно в списке.
2. В Happ добавить новую конфигурацию (кнопка `+`) — приложение подхватывает строку
   из буфера обмена.
3. Проверить, что профиль появился в списке, и подключиться.

### 3.3. Настроить роутинг

Без этого шага в туннель уйдёт весь трафик машины. Настройка одноразовая.

1. Открыть настройки Happ → **Routing rules**.
2. Если роутинга ещё нет — создать новый и **включить** его.
3. Зайти в настройки созданного роутинга → **Edit rules** → раздел **Direct**.
4. Добавить в `Direct` три строки:

```
geoip:ru
powbeecrm.com
github.com
```

Что делает каждая:

| Правило | Что идёт напрямую, мимо туннеля |
|---|---|
| `geoip:ru` | всё, что размещено в России: Трекер, Вики, почта, внутренние сервисы, боевые и тестовые стенды |
| `powbeecrm.com` | наш рабочий домен вместе с поддоменами — админки и приложения клиентов |
| `github.com` | репозитории: `git pull`, `push`, PR |

Названия пунктов меню на разных платформах и версиях отличаются в мелочах —
логика одна: раздел правил роутинга, список `Direct`, три строки выше.

### 3.4. Проверить

VPN включён, роутинг настроен — проверяем обе стороны:

- Claude Code запускается и `/login` проходит — значит, туннель работает.
- Трекер, Вики и стенд клиента открываются как обычно — значит, `Direct` настроен
  и рабочий трафик мимо туннеля идёт.

Открывается одно, но не другое — дело почти всегда в п. 3.3: либо роутинг не включён,
либо правила добавлены не в `Direct`.

## 4. Правила пользования

- **Конфигурация персональная.** Одна строка — один человек. Делиться ею нельзя:
  это и обход выдачи доступа, и потеря следа, кто чем пользовался.
- **VPN — для работы с Claude Code**, а не общий доступ в интернет для личных задач.
- **Рабочие данные через туннель не гоняем.** Правила `Direct` из п. 3.3 ровно для
  этого и нужны — не убирай их «чтобы быстрее открывалось».
- **Проблемы с подключением** — к CTO, он выпускал конфигурацию. Не чинить подбором
  чужих конфигураций и сторонних клиентов.
