## Назначение

Рабочее место сотрудника «в полях»: работа с данными из [pbeadmin](pbeadmin.md)
на телефоне и в вебе. Поставляется под брендом каждого клиента-фармкомпании.

## Серверная часть — два подхода

Репозиторий `pbeapp` содержит только клиент (Angular + Capacitor). Серверная
логика приложения реализуется одним из двух способов:

| Подход | Где живёт | Кто ведёт |
|---|---|---|
| Через API [pbeadmin](pbeadmin.md) | PHP-код админки | Отдел «Админки» |
| Напрямую в MSSQL | Боевая БД: процедуры, представления, запросы | Ипполитова Светлана |

Второй подход объясняет, почему у Светланы `db_owner` на PROD: для этой работы
БД — не источник данных, а среда разработки. Управленческое следствие: часть
логики приложения не проходит через обычный цикл ревью и релиза кода, потому что
живёт не в репозитории. TODO: оценить, нужен ли для неё отдельный порядок
контроля изменений.

## Мультибренд — ключевая особенность

Приложение собирается под **16 брендов**, ~47 build- и 46 serve-конфигураций
в `angular.json`. Схема имён скриптов: `<бренд>:<serve|build>:<среда>`.

| Код | Бренд | Код | Бренд |
|---|---|---|---|
| `ser` | Servier | `aci` | Acino |
| `bsn` | Besins | `roc` | Roche |
| `vlt` | Valenta | `alpen` | Alpen Pharma |
| `boe` | Boehringer *(только web)* | `may` | Mayoly |
| `avx` | Avexima | `xantis` | Xantis *(только web)* |
| `bay` | Bayer | `sal` | Salvim *(легаси)* |
| `bay-by` | Bayer, белорусский контур | `prima` | Prima *(легаси)* |
| `demo` | демо-стенд | `bnf` | BNF *(легаси)* |

Управленческое следствие: любое изменение в общем коде (`commons/`,
`components/`, `services/`) затрагивает **все** бренды — регрессия
масштабируется на всех клиентов сразу. Легаси-бренды (`bnf`, `prima`, `sal`)
намеренно без npm-скриптов.

## Дорожная карта модернизации

Зафиксированные цели, каждый шаг — отдельная ветка и PR, без «больших взрывов»:

1. **Angular 18 → 22** — строго по одному мажору за шаг, после каждого зелёная сборка всех брендов.
2. **Capacitor 6 → 8** — синхронно с Angular, с проверкой всех плагинов.
3. **NgModule → standalone** — по одному модулю за итерацию; блокер — механизм брендовой композиции (`optionalModules`), его замена проектируется отдельно.
4. **RxJS 6 → 7** — обязательный пре-шаг дорожки Angular.
5. **Zoneless** — отдалённая цель после standalone.
