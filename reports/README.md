# Отчёты и выгрузки

**Содержимое папки не коммитится.** В git только этот файл — всё остальное
исключено в [`.gitignore`](../.gitignore) правилом `reports/*`.

## Зачем так

Отчёты собираются скриптами из Трекера, Вики и БД. Они:

- **воспроизводятся командой** — хранить результат в git незачем, достаточно знать,
  чем он получен;
- **содержат ФИО, трудозатраты и оценки по людям** — данные внутренние, в истории
  репозитория им не место;
- **устаревают за дни** — закоммиченный отчёт через месяц врёт, но выглядит
  достоверно.

Если из отчёта родился вывод, который нужно сохранить — он идёт не сюда, а в
[docs/](../docs/): решение — в соответствующий документ, открытый вопрос —
в [docs/backlog.md](../docs/backlog.md). Сюда складываются сами выгрузки.

## Как наполняется

```bash
# отчёт по спринтам: оценка, факт, возвраты, сроки → reports/<имя>.md и .csv
automation/scripts/tracker-project-report.py 926 930 --save
```

Имя файла скрипт составляет из номеров проектов и даты сборки:
`tracker-projects-926-930-2026-08-12.md`. Дата в имени обязательна — без неё
через три запуска непонятно, какой из файлов свежий.

Класть сюда что-то руками тоже можно; тогда в первой строке файла указывайте
дату и чем он собран.
