Работа с задачей Трекера: **$ARGUMENTS**

## 1. Прочитать

```
automation/scripts/tracker-issue.sh <ключ>
```

Выгружает поля, описание, все комментарии, связи и вложения. Ключей можно передать
несколько — разделитель в выводе — строка `---`.

Если в задаче или её комментариях есть **ссылка на Вики** — открой страницу
и прочитай её тоже:

```
automation/scripts/wiki-page.sh <ссылка целиком>
```

Страницу, которую не удалось открыть, назови явно. Молча пропущенная ссылка —
это разбор по неполным требованиям.

## 2. Разобрать

Ответ строй в таком порядке, коротко:

1. **О чём задача** — своими словами, два-три предложения.
2. **Где она сейчас** — статус, исполнитель, чей ход, сколько висит.
3. **Что прочитано** — какие комментарии и страницы Вики учтены.
4. **Чего не хватает** — вопросы, без ответа на которые задача не двигается.
5. **Что предлагаю сделать** — одно-два действия, а не список возможностей.

Ничего не выдумывай. Нет в задаче срока — так и скажи, не подставляй правдоподобный.

## 3. Ответить или завести

Оба действия **пишут в Трекер и делаются только с явного подтверждения человека**.
Порядок один и тот же: черновик в файл → показать → дождаться «да» → отправить.

Черновик клади в папку сегодняшнего дня: `reports/<ГГГГ-ММ-ДД>/<ключ>-otvet.md`.

**Комментарий в существующую задачу:**

```
automation/scripts/tracker-update.py <ключ> <файл>.md --comment            # сухой прогон
automation/scripts/tracker-update.py <ключ> <файл>.md --comment --apply    # отправка
```

**Новая задача:**

```
automation/scripts/tracker-create.py <пресет> <файл>.md            # сухой прогон
automation/scripts/tracker-create.py <пресет> <файл>.md --apply    # создание
```

Первый заголовок первого уровня в файле становится названием задачи, всё после
него — описанием.

Три правила, которые не обходятся:

- **Без `--apply` ничего не уходит.** Сухой прогон показывает, что было бы отправлено, —
  сначала всегда он.
- **Отменить нельзя.** Задачу можно только закрыть, комментарий остаётся в истории
  и уходит подписчикам. Поэтому текст вычитывается до отправки, а не после.
- **Статус задачи не трогаем.** Перевод статуса — подпись человека под словами «работа
  сделана», а не техническое действие.
